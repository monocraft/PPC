# Project data

The latest editable portfolio package is stored locally at:

`project-data/private/product-portfolio-project.pkg`

It contains the working portfolio content (85 products across 11 categories) and
one embedded image blob. The package is intentionally ignored by Git and omitted
from the GitHub Pages artifact because it may contain internal portfolio data.

To work with the latest content, start the local server, open the app, choose
**Data → Import project package**, and select that file. Export a new project
package after making content changes.

Baseline SHA-256:

`3FB436E56FAE28CC7FE125030841690039084679C15619CDDC763DA6D2D5B3A4`

Do not move the package into a deployed directory or remove the ignore rule
without an explicit decision to publish its contents.
